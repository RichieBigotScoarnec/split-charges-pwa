1. Ouvrir Firebase Console :
   👉 https://console.firebase.google.com/project/split-charges/database/split-charges-default-rtdb/rules

2. Dans l'éditeur de règles, REMPLACER tout le contenu par :

{
  "rules": {
    "salaries": {
      "$uid": {
        ".read": "auth != null && (auth.uid === $uid || root.child('partners').child(auth.uid).val() === $uid)",
        ".write": "auth != null && (auth.uid === $uid || root.child('partners').child(auth.uid).val() === $uid)"
      }
    },
    "periods": {
      "$uid": {
        ".read": "auth != null && (auth.uid === $uid || root.child('partners').child(auth.uid).val() === $uid)",
        ".write": "auth != null && (auth.uid === $uid || root.child('partners').child(auth.uid).val() === $uid)"
      }
    },
    "shareMode": {
      "$uid": {
        ".read": "auth != null && (auth.uid === $uid || root.child('partners').child(auth.uid).val() === $uid)",
        ".write": "auth != null && (auth.uid === $uid || root.child('partners').child(auth.uid).val() === $uid)"
      }
    },
    "reminders": {
      "$uid": {
        ".read": "auth != null && (auth.uid === $uid || root.child('partners').child(auth.uid).val() === $uid)",
        ".write": "auth != null && (auth.uid === $uid || root.child('partners').child(auth.uid).val() === $uid)"
      }
    },
    "partners": {
      "$uid": {
        ".read": "auth != null && (auth.uid === $uid || root.child('partners').child(auth.uid).val() === $uid)",
        ".write": "auth != null && auth.uid === $uid"
      }
    }
  }
}

3. Cliquer sur "Publier" (bouton bleu en haut)

4. Attendre le message de confirmation

5. Actualiser l'application dans votre navigateur

✅ L'APPLICATION DEVRAIT FONCTIONNER IMMÉDIATEMENT !

📝 EXPLICATION DES RÈGLES

Ces règles sécurisées permettent :

1. **Accès Owner** : L'utilisateur peut accéder à ses propres données
   → auth.uid === $uid

2. **Accès Partner** : Le partenaire lié peut accéder aux données de l'Owner
   → root.child('partners').child(auth.uid).val() === $uid

   Exemple : Si partners/uidPartner = uidOwner, alors Partner peut lire
   et écrire dans salaries/uidOwner, periods/uidOwner, etc.

3. **Lien bidirectionnel** : Les deux partenaires peuvent lire leurs
   configurations respectives via partners/$uid

⚠️ IMPORTANT : Les deux partenaires voient et modifient LES MÊMES DONNÉES.
   C'est voulu pour un couple partageant les charges communes.
